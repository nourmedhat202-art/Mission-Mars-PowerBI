# 🚀 MISSION: MARS

## 📊 Project Overview

Mission: Mars is an interactive Power BI dashboard based on a simulated Mars exploration mission.

The project transforms mission data into meaningful visual insights, covering rover activity, mission progress, environmental conditions, available resources, exploration locations, scientific samples, and research priorities.

## 🎯 Project Objectives

- 🚀 Track rover distance and mission progress
- 🌡️ Analyze Mars weather and environmental conditions
- ☢️ Monitor radiation and dust storm levels
- 💧 Track oxygen, water, energy, and fuel resources
- 🤖 Analyze rover activity and scientific samples
- 📍 Explore mission locations and research priorities

## 🛠️ Tools & Technologies
